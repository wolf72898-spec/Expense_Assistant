## 复现步骤

```bash
# 1. 业务挖掘：驱动实验室完成 6 岗位访谈并导出发现报告
python scripts/fde_interview.py --scenario construction-change

# 2~4. 行业分析、流程图、报价与方案
python scripts/gen_industry_docx.py
python scripts/gen_flowcharts.py
python scripts/gen_solution_docx.py
python scripts/gen_quote_xlsx.py
```

前四步只需 Python 标准库 + `python-docx` / `matplotlib` / `openpyxl`
（见仓库根目录 `requirements.txt`）。第 1 步需要能访问实验室站点。

## 三条必须知道的前提

1. **场景是合成案例**。事实来自角色口述，需求是**待验证假设**，不等于已确认的业务需求。
2. **覆盖率 34/36**。实验室接口在两处出现 502，脚本按容错策略跳过；缺失 2 条已如实标注。
3. **AI 不得作为质量安全判定依据**。所有阻断与签认须由具备资格的人员完成——
   这是设计方案里的硬约束，不是免责声明。
